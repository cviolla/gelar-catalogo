Correção de Banco de Dados

Detectamos que seu Supabase ainda não tem a coluna de imagens ou tabelas necessárias. Copie o código abaixo e rode no SQL Editor do seu projeto Supabase:

-- 1. Cria ou Atualiza Tabela de Produtos create table if not exists products ( id uuid default gen_random_uuid() primary key, name text, price float8, category text, stock int, image text, created_at timestamp with time zone default now() ); -- 2. ADICIONA COLUNAS ESTRUTURAIS -- 2. ADICIONA COLUNAS ESTRUTURAIS alter table products add column if not exists image text; alter table products add column if not exists is_deleted boolean default false; -- Opcional: Se der erro de politica duplicada (policy already exists), rode: -- drop policy if exists "Acesso Total Produtos" on products; -- 3. Cria ou Atualiza Tabela de Histórico create table if not exists ideashistory ( id uuid default gen_random_uuid() primary key, title text, type text, caption text, visual text, cta text, archived boolean default false, created_at timestamp with time zone default now() ); -- 4. Adiciona a coluna de arquivamento se faltar alter table ideashistory add column if not exists archived boolean default false;

Após rodar no Supabase, tente importar novamente.
